# 以利亚的至暗时刻 — 视频短剧系列

> 将圣经中最震撼人心的"属灵低潮"故事，转化为视觉化的短剧体验。

---

## 制作理念

### 核心定位
- **类型**：圣经历史短剧 / 灵性叙事短片
- **时长**：每集 5-8 分钟
- **风格**：电影级叙事，氛围感优先，台词精简，画面传达情感
- **受众**：教会青年群体、慕道友、短视频平台用户
- **语言**：中文（可采用中英双语字幕）

### 视觉风格
- **色调**：暖黄（迦密山胜利）→ 灰白（旷野）→ 深蓝与暗红（至暗时刻）→ 晨曦金（恢复）
- **摄影**：大量空镜、慢镜头、特写（眼神、手、尘土、火焰）
- **音乐**：中东风器乐（乌德琴、耐笛）+ 现代氛围垫音
- **字幕**：关键经文以书法体叠印在画面上

### 叙事手法
- **主线**：以利亚的内心旅程（外显为物理旅程）
- **旁白**：以第一人称（以利亚的回忆）或第三人称"叙事者"视角
- **闪回**：迦密山胜利的片段在逃亡中闪回，形成对比
- **留白**：关键情感时刻不做台词填充，留给画面和音乐

## 剧本格式说明

每集脚本包含以下要素：

```
【集数·标题】
时长：Xmin | 对应经文：XXX

【场景 X — 标题】
时间：白天/黄昏/夜晚
地点：具体地点
人物：在场角色
氛围：情感基调

[画面描述]
  视觉细节、镜头运动、构图

[旁白/对白]
  说话者：内容

[字幕建议]
  显示在屏幕上的文字

[音乐/音效]
  背景音乐、环境音、音效提示

[转场]
  如何过渡到下一场景
```

## 制作建议

### 低预算方案
- 使用沙漠/旷野实景拍摄（以色列/约旦，或国内西北戈壁替代）
- 单人演员为主（以利亚一人撑起大部分戏份）
- 大量依赖光影、音乐而非特效
- 关键镜头（迦密山烈火）可用后期合成

### 中等预算方案
- 添加群演（迦密山百姓、巴力先知）
- 专业配乐录制
- 场景搭建（何烈山洞穴内景）

### 高预算方案
- 全实景以色列拍摄
- 动物镜头（乌鸦叼饼、马匹）
- 火焰特效（迦密山天火）
- 专业电影摄影
