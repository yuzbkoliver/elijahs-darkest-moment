# 剧本格式规范

> 本系列所有脚本统一使用以下格式标准。

---

## 通用格式

### 文件命名
```
S{集数}-{标题}.md
```
示例：`S01-迦密山的烈火.md`

### 页眉
每集脚本开头包含标准元数据块：
```
【集数·标题】
时长：Xmin | 对应经文：XXX
```

---

## 场景块格式

每个场景由以下区块组成，**严格按此顺序**：

### 1. 场景标题
```
【场景 X — 标题】
```
- 场景编号按顺序递增（1, 2, 3...）
- 标题简短描述核心事件

### 2. 元数据
```
时间：白天/黄昏/夜晚/黎明
地点：具体地点
人物：在场角色（以粗体标注主要角色）
氛围：情感基调
```

### 3. 画面描述
```
[画面描述]
```
- 使用现在时态
- 包含镜头提示（远景、特写、慢镜等）
- 描述视觉细节（光线、色彩、质感）
- 每段不超过 50 字，保持节奏感

### 4. 旁白/对白
```
[旁白]
  内容

[对白]
  人物：内容
```
- 旁白用中文，注明是"以利亚之声"（第一人称）还是"叙事者"（第三人称）
- 对白标注说话者
- 圣经直接引用用**加粗**标出

### 5. 字幕建议
```
[字幕]
```
- 出现在屏幕上的经文引用
- 关键台词的字幕
- 地点/时间标题卡

### 6. 音乐/音效
```
[音乐]
  描述风格、乐器、情绪

[音效]
  环境音、具体声音效果
```

### 7. 转场
```
[转场方式]
```
- 淡出/淡入、切黑、叠化、匹配剪辑等

## 格式示例

```
【场景 3 — 迦密山顶】
时间：午后
地点：迦密山顶，祭坛旁
人物：以利亚、亚哈、百姓（群演）
氛围：紧张、期待、寂静

[画面描述]
  远景：迦密山顶，天空湛蓝。
  以利亚站在修复的祭坛旁，十二块石头整齐排列。
  镜头推近：他的双手平稳，眼神坚定。

[旁白 — 以利亚之声]
  我修好了被毁坏的祭坛。
  不是因为我有多大的信心。
  而是因为我在这个时刻，已经没有退路。

[对白]
  以利亚：你们将水倒在燔祭和柴上！
  百姓：（窃窃私语，传递水桶）

[字幕]
  「求耶和华降下火来」— 列王纪上 18:37

[音乐]
  开始：低沉的弦乐长音，持续渐强
  中段：加入中东鼓点，心跳般的节奏

[音效]
  水倒在石头上的声音
  风声渐起

[转场]
  叠化至下一场景
```

---

## 符号说明

| 符号 | 含义 |
|------|------|
| `[ ]` | 画面/音乐/音效/字幕描述 |
| **( )** | 镜头运动提示 |
| **加粗** | 圣经原文引用 |
| `[旁白]` | 配音/画外音 |
| `[对白]` | 角色台词 |
| `[转场]` | 场景切换方式 |

---

## 时长参考

| 元素 | 建议时长 |
|------|----------|
| 单场景 | 30-90 秒 |
| 旁白段落 | 15-30 秒 |
| 对白段落 | 10-20 秒 |
| 无对白镜头 | 5-15 秒 |
| 单集总长 | 5-8 分钟 |
| 全系列 | 约 60-80 分钟 |
