# 以利亚的至暗时刻

> **Elijah's Darkest Moment — 从迦密山到罗腾树，从崩溃到重新得力**

---

## 图书简介

先知以利亚——以色列历史上最伟大的先知之一，迦密山上烈火从天而降，他一人独战四百五十个巴力先知，凯旋之后却因耶洗别一句威胁，仓皇逃命，在旷野的罗腾树下求死。

这是圣经中最震撼人心的"属灵低潮"故事。本书将带领读者深入以利亚的内心世界，探索：

- 为什么最伟大的胜利之后往往是最脆弱的时刻？
- 神如何与破碎中的人相遇？
- 从"至暗时刻"到"重新得力"的路径是什么？
